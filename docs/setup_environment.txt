Use provided environment.yaml to create a environment

```conda env create --prefix ./env -f environment.yaml```

Activate the environment

```conda activate ./env```

Or create an isolated virtual environment

Alternative (if you want pip-only, isolated to directory):

```
python -m venv ./env
source ./env/bin/activate  # Linux/Mac
# or
.\env\Scripts\activate     # Windows
pip install -r requirements.txt
```
